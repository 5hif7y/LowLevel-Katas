# Unix: lib/dbus (nuevo) + service/netenv en Linux — informe

**Archivos.** `odin/lib/dbus/` (`pm_dbus`): `dbus.odin` (tipos, errores, constantes), `signature.odin` (firmas, nombres), `marshal.odin` (wire format, ambos endianness, clone/destroy), `message.odin` (header, marshal/unmarshal, helpers de body), `address.odin` (direcciones, system/session bus), `conn.odin` (SASL EXTERNAL, Hello, hilo lector, call, propiedades, señales), `transport_unix.odin` (`#+build !windows`, `core:sys/posix`), `transport_windows.odin` (stub `.Not_Supported`: Portmaster nunca usa D-Bus en Windows; el formato compila y se testea igual), `dbus_test.odin`. `odin/lib/dbus/dbustest/` (`pm_dbustest`, `#+build !windows`): bus falso reutilizable + tests de conexión (no pueden vivir en `lib/dbus`: dbustest importa dbus → ciclo). `odin/service/netenv/`: nuevos `os_linux.odin` (netlink), `environment_linux.odin`, `interfaces_linux.odin`, `dbus_linux.odin`, `location_linux.odin` (traceroute), `os_unix_todo.odin` (`#+build !windows` + `#+build !linux`: macOS/BSD), `netenv_linux_test.odin`, `environment_windows_test.odin`; reescrito `os_other.odin` (zona horaria + udp_poll comunes a unix); tocados `main.odin` (kinds `Netlink_Failed`, `Read_Routes_Failed`; variante `Error_Text`), `os.odin` (`Adapter.os_flags`), `environment.odin` (`destroy_nameservers` con listas de search distintas), `location.odin` (comentario). Tests `netenv_test`, `location_test`, `online_status_test` sin `#+build windows` (corren en Linux).

**Portado.** dbus_linux.go entero (PrimaryConnection primero, luego ActiveConnections sin repetir; IPv4 `au` con la aritmética de Go, IPv6 `aay` con error si len≠16; Domains+Searches; Connectivity 0..4 → Unknown/Offline/Portal/Limited/Online). environment_linux.go: Gateways/GatewaysInfo (`gateways_info`, `Gateway_Info{ip, interface, mask, mask_len}`) desde /proc/net/route e ipv6_route, Nameservers (D-Bus + resolv.conf, caché por network-changed flag, copias), addNameservers con IP.Equal. interfaces_linux.go: candidatos por /proc + `/sys/class/net/<if>/device`, menor métrica con dirección ruteable. `net.Interfaces`/`InterfaceAddrs` de Go = dumps RTM_GETLINK/RTM_GETADDR por netlink (`core:sys/linux`, sin privilegios), con las reglas de Go (IFA_LOCAL antes que IFA_ADDRESS, MAC nula o de túnel IP se descarta). Traceroute: socket raw ICMP (lo que abre Go; root/CAP_NET_RAW) y si no, "ping socket" SOCK_DGRAM con IP_RECVERR (time-exceeded/unreachable por la cola de errores, router en SO_EE_OFFENDER). Zona horaria: `core:time/timezone` "local" (como base/log).

**PORT-TODO(darwin)** (`os_unix_todo.odin`): `get_adapters` (getifaddrs + sysctl NET_RT_IFLIST; `core:sys/posix` no los tiene) y el prober ICMP. `gateways`/`nameservers` = nil y physical default = `.Not_Supported` son lo que hace Go en darwin (`environment_default.go`, `interfaces_default.go`), no stubs. No queda `PORT-TODO(unix)` en el alcance.

**Hooks / reemplazables.** `netenv.dbus_connect` (default `dbus.system_bus`; tests → bus falso), `netenv.is_sysfs_physical`, `close_dbus_connection()` (tests). Nada nuevo para otras etapas.

**API de lib/dbus (para keyring y notificaciones).**
- Valores: `Value` union de `u8 bool i16 u16 i32 u32 i64 u64 f64 string Object_Path Signature Unix_Fd Byte_Array Array Dict Struct Variant`. `Array{elem, items}`, `Dict{key, value, entries: []Dict_Entry{key, value}}`, `Struct{fields}`, `Variant{sig, value: ^Value}`; `ay` siempre `Byte_Array`. Helpers: `variant(v)` (calcula la firma, temp), `string_dict({{"k","v"}})` (a{ss}), `value_signature`, `value_clone/value_destroy`, `variant_value`, `dict_lookup`, `as_strings/as_object_paths/as_u32s/as_byte_arrays`, `arg(msg, i)`.
- **Trampa**: un literal de string sin tipo es ambiguo para `Value` (string / Object_Path / Signature son `distinct string`): escribir `string("x")`, `dbus.Object_Path("/x")`.
- Conexión: `system_bus()`, `session_bus()` ($DBUS_SESSION_BUS_ADDRESS o $XDG_RUNTIME_DIR/bus), `connect(addr)` (lista con `;`), `close(c)`, `is_closed(c)`, `c.unique_name`. Son conexiones privadas (godbus SystemBus() es compartida): el usuario guarda la suya, como netenv.
- Llamadas: `call(c, dest, path, iface, method, args, timeout = 25 s, flags) -> (^Message, Error)` — la respuesta es del llamador (`message_destroy`); un ERROR del otro lado vuelve como `.Remote` con `error_name(err)` y `error_string(err)` = mensaje (strings en temp). `.No_Reply_Expected` → `(nil, nil)` al enviar. `send`, `emit_signal`. `get_property(c, dest, path, "iface.Prop", allocator)` (como godbus GetProperty) / `get_property_of` / `set_property`.
- Señales: `subscribe(c, Match_Rule{sender, path, interface, member, arg0}, capacity) -> ^Subscription` (AddMatch + cola; sender sólo lo filtra el bus), `next_signal(sub, timeout)` (`.Timeout`/`.Closed`), `unsubscribe(sub)` (RemoveMatch). Cola llena → se descarta y cuenta `sub.dropped`. Las señales se copian en el hilo lector: no hay callbacks (un callback que llame a `call` desde el lector se trabaría).
- Secret Service (go-keyring): `OpenSession("plain", variant(string("")))` → (v, o); `SearchItems(string_dict(attrs))` → (ao, ao); `Unlock(ao)` → (ao, o prompt) + `subscribe({path = prompt, interface = "org.freedesktop.Secret.Prompt", member = "Completed"})` antes de `Prompt("")`; `GetSecret(session)` → `(oayays)` = `Struct{Object_Path, Byte_Array, Byte_Array, string}`; `CreateItem(a{sv}, (oayays), b)`; colección `/org/freedesktop/secrets/aliases/default`. Notifications: `Notify` `susssasa{sv}i` (image-data = `variant(Struct{i32,i32,i32,bool,i32,i32,Byte_Array})`), `CloseNotification(u)`, señales `ActionInvoked(us)` / `NotificationClosed(uu)`. Los round-trips de esas firmas están en `dbus_test.odin`.
- Bus falso (`pm:lib/dbus/dbustest`): `start({handler, user, abstract, reject_auth})`, `address(s)`, `set_property(s, path, iface, name, value)`, `emit_signal`, `calls(s)`, `matches(s)`, `auth_uids(s)`, `disconnect_clients(s)`, `stop(s)`. El handler devuelve `Reply{handled, args, error_name, error_message, no_reply, disconnect}`.

**Tests** (3 corridas cada uno, `-vet`; `odin check -vet` limpio):
- Linux (`lt.sh`, PM_MIRROR=/root/pm/agent-dbus): lib/dbus 15/15 ×3; lib/dbus/dbustest 9/9 ×3; service/netenv 51/51 ×3 (41 portables + 10 Linux).
- Windows: lib/dbus 15/15 ×3; service/netenv 42/42 ×3 (igual que antes). dbustest no corre en Windows (paquete vacío allí).
- `VET=1 bash odin/tests/crosscheck.sh windows_amd64 linux_amd64 darwin_arm64 -- odin/lib/dbus odin/lib/dbus/dbustest odin/service/netenv` → 9/9 ok.
- Opcionales: `-define:PM_DBUS_LIVE=true` (dbustest: Hello/GetId/Properties.Get contra el dbus-daemon real de WSL) → ok. `-define:NETENV_DBUS_LIVE=true` (TestDbus de Go) → falla en WSL porque no hay NetworkManager ("The name is not activatable"), igual que fallaría Go; por eso está apagado (Go lo salta con -short).
- Vectores: Hello byte a byte (128 B), señal big-endian, padding de arrays (también vacíos), structs/dict entries a 8, variant, rechazo de padding ≠ 0, bool ∉ {0,1}, UTF-8 inválido, NUL embebido, firmas inválidas y límites de profundidad 32/32 y largo 255.
- Netenv contra NetworkManager falso: orden primary-primero, `au`/`aay`, search = Domains+Searches, Ip6Config "/" saltado, IPv6 de largo inválido → sólo esa config falla, tipos equivocados → error con el texto de Go, mapeo de Connectivity, reconexión tras caída del bus, `nameservers()` = D-Bus + resolv.conf sin duplicados. Tabla netlink comparada con /sys/class/net (ifindex, mtu, MAC, flags). Prober ICMP raw y ping-socket contra 127.0.0.1.

**Bugs de Go.** Corregido: la conexión D-Bus de netenv nunca se renueva (si el bus se reinicia, todo falla hasta reiniciar Portmaster) → se reconecta si está cerrada. Corregido (cosmético): el warning de ipv6_route imprime `line[2]` en vez del gateway. Conservados: `search a b c` sólo toma `a` y líneas con tab se ignoran (SplitN por " "); ruta por defecto sin gateway da gateway 0.0.0.0 en GatewaysInfo; si /proc/net/route no se lee tampoco se lee ipv6_route y la caché queda vacía hasta el próximo cambio de red; `getConnectivityStateFromDbus` está portado pero Go no lo usa (comentado en online-status.go).

**Trampas.** (1) `#+build !windows !linux` es error de sintaxis: dos líneas `#+build` (se combinan con AND). (2) Literal de string → `Value` ambiguo (ver arriba). (3) `timezone.region_get_nearest` es privado: offset = reloj local (`datetime_to_tz`) leído como UTC menos `now`. (4) `[]u8(x)` de un `distinct []u8` no parsea: `([]u8)(x)`. (5) `transmute(u64)` de f64 es necesario; con enteros -vet exige cast — un sed que cambió ambos rompió `d` (lo atrapó el vector 1.0). (6) Tests de conexión no pueden ir en el paquete `pm_dbus` (ciclo con dbustest). (7) Bus falso: si el servidor corta, hay que `shutdown()` el fd o el cliente nunca ve EOF. (8) `runtime.Arena` sin `minimum_block_size` reserva 4 MiB por mensaje: se fija a max(4 KiB, 2×mensaje). (9) Una función que llama `or_return` con más de un resultado necesita resultados con nombre. (10) /proc/net/route reporta tamaño 0: `os.read_entire_file` lo maneja leyendo hasta EOF.
