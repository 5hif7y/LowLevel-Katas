# lib/tls (SChannel) + transportes del resolver — informe (13 + 17 tests, x3 y más)

- lib/tls: cliente TLS sobre SSPI/SChannel (bindings propios de secur32/ncrypt/crypt32): handshake con SEC_I_CONTINUE_NEEDED / SEC_E_INCOMPLETE_MESSAGE / buffers EXTRA / SEC_I_INCOMPLETE_CREDENTIALS, SEC_I_RENEGOTIATE, close_notify con ApplyControlToken(SCHANNEL_SHUTDOWN); SCH_CREDENTIALS TLS 1.2/1.3 con fallback a SCHANNEL_CRED; SNI = server_name sobre una conexión a IP; validación por el store de Windows o pin SHA-256 de la hoja; ALPN. Toda espera es WSAPoll en rebanadas de 50 ms sobre socket no bloqueante (nunca SO_RCVTIMEO). Servidor de test con AcceptSecurityContext y certificado autofirmado sólo en memoria (clave en un contenedor CNG de usuario con nombre único, borrado después; la carpeta de claves del usuario tenía 3 entradas antes y después).
- Transportes: UDP (semántica de ExchangeWithConnContext), TCP/DoT con pipelining, heartbeat, reciclado 5 min, IDs únicos y respuestas tardías cacheadas; DoH (GET ?dns= base64url sin padding como url.URL.String()); mDNS (bind compartido 5353 + grupos, sin admin); env.
- Smoke (desactivados por defecto) corridos una vez: DoT a 1.1.1.1:853 (TLS 1.2 en Win10), DoT+DoH a Cloudflare por los resolvers, mDNS. OK.
**Hueco abierto: DoH valida el certificado contra la IP, no contra Info.Domain** (WinHTTP toma SNI y nombre del host de la URL, que es la IP; Go conecta a la IP pero valida contra el dominio). Arreglo: DoH sobre lib/tls (que ya hace SNI = dominio sobre conexión a IP).
Bugs de Go corregidos: el handler TCP elige al azar entre ctx.Done y responses (select) → una respuesta llegada justo antes de que el servidor cierre podía perderse; envResolverConn llama CompatSubmitDNSCheckDomain sin chequear nil. Conservados: DoH no chequea bloqueo upstream ni el ID; mDNS guarda respuestas aunque la pregunta no coincida; domainInScope sensible a mayúsculas. Decisión: UDP plano conserva el "connection refused" inmediato (Go en Windows apaga SIO_UDP_CONNRESET); mDNS sí lo apaga.
Trampas: tls.DialContext(ctx) sólo acota el dial — guardar ese ctx en la Conn dejaba al lector usando un ctx liberado (SEC_E_DECRYPT_FAILURE del lado servidor, segfaults); claves autofirmadas con el mismo nombre en tests paralelos (timestamps en ns colisionan + NCRYPT_OVERWRITE_KEY_FLAG) → SEC_E_INTERNAL_ERROR intermitente → secuencia atómica; constantes SEC_E_* negativas; cstring16 vs LPWSTR con cast.
